# MESA (Multivariate Exploratory Signal Analysis)
## Contents
/src/mesa
contains the package and all implemented functionality.

/external
contains different examples as well as a convenient plate to locate data

/tests
contains several different tests to verify the correct functionality of the different modules in the package
